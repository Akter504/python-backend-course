# labs

Лабораторные работы по Python. Трек Backend, основной уровень.

Каждая работа находится в отдельной папке со своими исходниками, тестами,
зависимостями и инструкцией запуска.

| Работа | Содержание |
|---|---|
| [lab1](lab1/README.md) | Приём сдач, валидация и расширяемые анализаторы |

Следующие работы будут добавляться в папки `lab2`, `lab3` и далее.

```text
labs/
  README.md
  .gitignore
  .gitattributes
  lab1/
    README.md
    AI_USAGE.md
    pyproject.toml
    requirements-dev.lock
    config/
    data/
    src/lab1/
    tests/
```

Для запуска первой работы из корня репозитория перейдите в её папку:

```powershell
Set-Location lab1
```

Команды установки, запуска и проверки находятся в [README первой работы](lab1/README.md).
Git-команды для загрузки всех лабораторных выполняются из корня `labs`.
