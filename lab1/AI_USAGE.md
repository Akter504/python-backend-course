# Использование ИИ

При подготовке лабораторной работы я использовал OpenAI Codex для работы
с реализацией, тестами и документацией. Ниже указаны области применения инструмента.

## Применение

- Подготовка тестов обязательных сценариев и контрактов компонентов.
- Подготовка README, инструкций запуска и пояснений к устройству проекта.
- Разбор и исправление ошибок, найденных при проверках: типизация, кодировка
  вывода CLI в Windows и передача интерфейса чтения через контекст анализа.

## Проверки

Средствами среды разработки ИИ запускались pytest, Ruff, mypy, сборка пакета
и проверка установки в отдельное окружение. Последний полный запуск pytest
прошёл 120 проверок. Эти результаты относятся к автоматическим проверкам;

## Работа приложения

ИИ использовался для автоматического тестирования логики работы приложения, помощи в рутине.
Само приложение не вызывает модели:
анализаторы выполняют детерминированную обработку строк. Ограничения реализации
и команды воспроизведения проверок приведены в README.
